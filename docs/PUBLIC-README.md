# Планета для BeamNG.drive

Модификация BeamNG.Earth с меню выбора места, генерацией мира, навигатором и экспериментальным мультиплеером для двух игроков в локальной сети.

## Установка

Скачайте **Planet-Setup.exe** из Releases. Закройте BeamNG, выберите папку игры и отдельную папку «Планеты». Скопируйте показанную строку в Steam → BeamNG.drive → Свойства → Параметры запуска. Игра и её ресурсы в комплект не входят; установщик проверяет совместимость вашей версии.

Игра запускается через Steam, пункт **Планета** находится в главном меню. Интернет нужен для новых географических данных. Сессия между двумя ПК работает через Ethernet или общую локальную сеть: ведущий выбирает место и создаёт сессию, гость вставляет полный код подключения. При прямом кабеле укажите IPv4 интерфейса Ethernet в «Другой сетевой адрес», порт 3698/UDP.

Перед первым запуском помощник проверяет доступ сервера к локальной сети. Если разрешения нет, он объяснит настройку и запросит подтверждение Windows до открытия игры. Разрешается только установленный сервер, UDP 3698 и локальная подсеть. Уже выданное разрешение не запрашивается повторно. Пользовательские блокировки брандмауэра не снимаются автоматически. При отмене настройку можно повторить следующим запуском.

## Обновления и машины

Помощник проверяет Releases перед запуском (не чаще раза в 6 часов). Новый пакет проверяется по SHA-256 и внутреннему манифесту и устанавливается до запуска игры. При отсутствии сети остаётся установленная версия. Обновления не меняют машины, сохранения и кэш городов.

Для модовых машин установите одинаковые активные автомобильные моды и комплектации в оба профиля «Планеты». Установщик может скопировать автомобильные ZIP-моды из обычного профиля, включая отключённые там, по выбранному вами флажку. Моды автомобилей в релиз не включены и по сети автоматически не передаются. При различии ресурсов подключение объясняет причину.

## Статус и исходники

Это тестовая сборка. Автоматические проверки пакета, генерации, UI и сетевого протокола не заменяют проверку двух одновременно работающих игр. Точность городов зависит от исходных картографических данных.

`addon/` — интерфейс и Lua-интеграция; `companion/` — помощник Rust; `vendor/earth154/` — изменённый генератор; `vendor/planet-kissmp/` — сетевая часть; `tools/` — сборка и установка. Клиент BeamNG.Earth закреплён на коммите в `compat/earth153/manifest.json`; сборка применяет совместимые патчи. Для сборки нужны собственная совместимая BeamNG, Python с зависимостями генератора, Rust/MSVC и PyInstaller. Локальные пути и инструменты разработки настраиваются на вашей машине.

Основа: [BeamNG.Earth](https://github.com/TecnaGamer/BeamNG.Earth) и [KissMP](https://github.com/TheHellBox/KISS-multiplayer). Исходные лицензии и авторство сохранены. Этот проект не является официальным продуктом BeamNG.
